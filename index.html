Still getting Error 153?

Use the published https://…github.io/… page, not the local file preview. This page sets a referrer policy so the browser can send the site origin to YouTube. If Error 153 persists, check that your browser or an extension is not stripping referrers. Some videos also have embedding disabled or other playback restrictions; use “Open on YouTube” for those.

Floating mini-player requires a browser that supports Document Picture-in-Picture, such as recent desktop Chrome or Edge, and a secure HTTPS page.
